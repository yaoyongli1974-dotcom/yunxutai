# 云叙台 2.0 · 产品规格（阶段 A）

> 本文档描述 **PROPOSED**（2.0 目标状态），不描述现状。现状见 `00_CURRENT_CODEBASE_AUDIT.md`。

## 1. 产品定位

以个人和家族为核心，以数字档案为载体，以 AI 为整理工具，以家族协作为基础的家族记忆与数字文化传承平台。
在现有纪念馆能力之上升级，**不做并列新系统**：旧纪念馆、账号、核验、举报、AI 工作室、小程序继续有效。

## 2. 用户与场景

| 角色 | 核心诉求 |
|---|---|
| 馆主 / 家族创建者 | 建馆、邀请亲属、整理资料、控制公开范围 |
| 家族成员（有账户） | 协作补充人物、照片、故事，参与审核 |
| 被记录的家族人物（可无账户） | 其资料由家属代管；活人信息默认私密 |
| 访客 / 亲友 | 经授权查看纪念馆、谱系、展馆、档案 |
| 管理员 | 核验身份、处理举报/争议、审计、配置 AI 服务 |

## 3. 五大业务中心（PROPOSED）

### 3.1 纪念空间（保留并增强）
- 现有：纪念馆、生平文章、献花/留言（待审）、媒体、公开列表、核验门槛、认领/举报。
- 2.0：纪念馆可关联 `family_persons`；人物时间线与馆内 `life_events` 互通；不删除现有字段与权限语义。
- 验收：旧馆创建/编辑/访问/API 全部回归通过。

### 3.2 家族空间
- 家族创建/编辑/停用、头像、简介、隐私（`private` / `unlisted` / `public`），owner/admin/genealogy_editor/archive_editor/member/guest 角色。
- 成员邀请（有效期 + 令牌）、接受/拒绝/撤销、移除、退出、角色调整、全员审计。
- 一人可加入多家族；切换时必须重新加载上下文与权限（不是换前端标题）。
- 家族主页统计必须按“当前用户有权查看的数据”计算。

### 3.3 数字档案馆
- 档案（文字/照片/视频/音频/文献）创建、编辑、归档、删除申请、分类、标签、搜索、筛选、版本、导出。
- 原文件与处理副本分离；SHA-256、MIME 白名单、大小限制、EXIF 清理、缩略图/封面、下载鉴权与审计。
- 档案↔人物↔事件多对多关联；照片人工区域标注（坐标 + 人物 + 确认状态），首期不做人脸识别。
- 家族间档案完全隔离；禁止业务层拼接公开文件 URL。

### 3.4 AI 家族记忆工坊
- 保留现有 AI Studio；扩展为统一工作流：OCR、语音转写、口述历史采访助手、人物/事件提取、人物传记、家族史生成。
- 所有 AI 输出都是**候选/草稿**：pending → confirmed/disputed/rejected；必须保存模型、Provider、提示词版本、输入引用、输出版本、生成时间、创建者、修改记录、审核状态。
- 禁止：AI 推测自动成为正式事实、自动覆盖人物档案、未授权私密资料外发、自动发布未校正转写稿、编造历史（资料不足标记“未知/待核实”）。
- 可靠性：幂等、原子领取、租约、超时恢复、最大重试、指数退避、失败分类、取消、清理与补偿。

### 3.5 家族谱系与时间轴 / 展馆 / 通知
- 谱系：人物（可与账户分离）、重复人物合并（保留关联与审计）、关系方向/反向统一定义、审核与争议、支系、按需加载、移动端缩放拖动；禁止自关联/重复/非法循环。
- 时间轴：家族/人物/迁徙/活动事件，来源可追溯，按人物/时间/类型筛选；纪念日提醒（站内 + 现有通知通道，可关闭非必要提醒）。
- 展馆：草稿/审核中/已发布/已下线；关联人物、馆、档案、事件、文章、多媒体；响应式展示；机构租户仅预留数据隔离能力，不做计费 SaaS。
- 通知中心：邀请、加入、关系待审、档案审核、AI 完成、口述历史审核、纪念日、展馆审核、导出完成；站内已读/批量已读/偏好/失败重试/日志；通知失败不影响主事务。

## 4. 关键规则（不可妥协）

1. 活人资料默认私密；公开展示需明确授权；私人信件、采访录音默认不公开。
2. 所有家族数据查询具备 `family_id` 隔离；后端 Policy 校验，前端权限仅用于展示。
3. 默认拒绝；未授权资源返回 404/403 且不泄露是否存在。
4. 已退出/封禁成员不能通过旧链接或旧令牌继续访问。
5. AI 生成内容不得自动确认；重要事实必须可追溯到原始资料或人工提交。
6. 敏感身份材料加密存储，密钥与数据分离；下载需记录原因；备份加密；支持撤回授权、导出、依法删除。
7. 数据库变更使用独立迁移，禁止 DROP/重命名/破坏现有生产表与数据。
8. Web 与 `/api/v1` 共用同一业务逻辑与 Policy；小程序仅消费 API。

## 5. 非目标（首期）

- 微服务、消息队列中间件（Kafka/RabbitMQ）、独立 AI 服务部署。
- 复杂 SaaS 多租户计费、虚拟祭品商城、游戏化排行榜。
- 自动人脸识别、默认用家族照片训练模型。
- 一次性加载全家族谱系、全量自动发布 AI 内容。
- 重写认证流程、替换 MySQL、废弃现有纪念馆功能。

## 7. 产品级验收清单

- 家族可创建/编辑/停用，邀请流程完整，多家族切换正确。
- 人物（含无账户）可管理、可合并且不丢档案；关系方向准确、争议可处理。
- 纪念馆可关联家族人物，旧馆功能与权限不变。
- 档案上传/下载鉴权、版本、跨家族隔离全部通过。
- AI 结果均需人工审核，来源可追溯，任务异常可恢复。
- 展馆基础可用，Web 与小程序核心业务一致。
- 活人隐私、私密档案、敏感文件、外部 AI 调用授权、管理员审计、导出/删除流程均通过安全验收。
